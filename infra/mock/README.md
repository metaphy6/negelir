# Mock data root — Phase 2 dev stack ("Fake Internet")

This tree backs the local stack that mirrors mackolik / nesine / tff /
openfootball over a self-signed CA so the scrapers never hit the real
internet during development or CI.

Layout:

```
infra/mock/
├── ca/         ← self-signed root CA (generated by `make mock.ca-init`)
├── certs/      ← per-vhost leaf certs (generated by `make mock.ca-init`)
├── seeds/      ← frozen captures (manifest.json + payload files)
└── nginx/      ← nginx-mock vhost configs (Phase 2.1)
```

See `docs/planning/ROADMAP.md` Phase 2 and the source-watcher sub-phase
2.8 for the full plan.

> ⚠️ This directory is currently a **scaffolding** drop. The CA, certs,
> and nginx vhosts are generated by future `make mock.*` targets.
