### 13.9 Performance, efficiency, & footprint

- [x] **Catalog footprint cap.** Loaded catalog (50 rows + 200 competitions) ≤ `cfg.league_catalog_max_rss_mb` (default 8 MB resident); soak test `test_catalog_rss_under_cap.py`. Landed: `ai/tests/test_league_catalog_memory.py` loads full catalog via `LeagueCatalogLoader.load_all()`, measures RSS via `psutil.Process().memory_info().rss`, asserts <= cap; nightly CI benchmark tracked in `data/bench/league_memory_rss.json` with trending alerts.
- [x] **Lazy preset import.** `LEAGUE_CONFIGS` is a `LazyDict` — a preset module is imported only when its `league_id` is first accessed. Predictor cold-start with 30 leagues stays within Phase 11 §11.0 cold-start budget; benchmarked nightly (`make bench.leagues_coldstart`). Landed: `ai/common/lazy_dict.py` implements `LazyDict` (inherits `dict`, overrides `__getitem__` to import on first access); preset modules are functions returning config (not inline dicts); cold-start benchmark `make bench.leagues_coldstart` runs 30 preset loads + predictor init, reports P99 latency vs budget; proof test `test_lazy_dict_imports_on_access.py` verifies no import until first access.
- [x] **Gazetteer compile cache.** TR gazetteer compiled per league set + cache key `sha256(league_ids_sorted, gazetteer_version)`; recompile cost bounded; cache eviction LRU by Phase 11 §11.15 artifact-cache discipline. Landed: `ai/nlp/gazetteer_compiler.py` caches compiled gazetteer in Redis with TTL=`cfg.gazetteer_cache_ttl_h` (default 24 h); key format: `gazetteer:v<version>:<league_ids_hash>`; LRU eviction per artifact-cache contract; hit/miss metrics exported; proof test `test_gazetteer_cache_keyed_by_league_set.py` verifies cache hit on repeated set, cache miss on set mutation.
- [x] **Predictor replica admission.** Adding a league does **not** auto-spawn replicas; the Phase 8 scaler reads per-league traffic and requests new replicas through Phase 11 §11.34 preflight. Capacity refusal returns a structured reason; ops sees it on the console. Landed: Phase 8 scaler (not directly Phase 13; reference only); Phase 11 admission gate checks `cfg.predictor_replica_max` + current count; refusal returns `AdmissionDenied{reason: "predictor_replica_at_cap"}` to catalog update; ops console renders denial reason; proof test `test_adding_league_does_not_auto_spawn_replicas.py` verifies no replica change on catalog update.
- [x] **Tenant quota hooks** (Phase 20 dormant) — every league row carries a `default_tenant_class` so quota counters in §11.17 partition correctly when monetization flips on. Landed: `default_tenant_class: str` field in League dataclass (values: `free`, `pro`, `enterprise`); used by Phase 11 quota gate (not active in Phase 13); default=`free`; lint enforces non-null; proof test `test_league_catalog_default_tenant_class_not_null.py` verifies field set on all rows.
- [x] **Catalog hot-reload (advisory).** Operator calls `make leagues.reload`; predictors that have already pinned a row continue with the prior view until next request — no in-flight prediction is interrupted (proof test `test_hot_reload_no_inflight_break.py`). Landed: `make leagues.reload` target in Makefile dispatches to `xops/makefile/leagues.py` + `reload` subcommand; reloads catalog from disk in Redis (versioned key); in-flight predictors hold reference to prior version via snapshot + TTL; new requests use new catalog; proof test spawns prediction task + concurrently reloads catalog, verifies task completes with pre-reload view.
- [x] **Per-league embedding budget.** Cross-competition identity (§13.4) reuses one shared embedding model across all leagues; per-league dedicated models are **forbidden** by lint (doctrine #4 — smallest model that works). Landed: `xops/lint/embedding_doctrine.py` enforcer scans for any per-league model imports; error if found; shared embedding model pinned in `ai/model/embedding.py` + config; proof test `test_embedding_doctrine_enforced.py` asserts lint catches per-league model attempt.
- [x] **Catalog memory growth bound.** `bench/leagues_memory.py` asserts adding a league row grows resident memory by ≤ `cfg.league_per_row_max_kb` (default 64 KB) under realistic competition counts; regressions block CI. Landed: benchmark loads N leagues, measures RSS delta, divides by N to get per-row cost; nightly CI run (`make bench.leagues_memory`) asserts delta <= cap; failure blocks merge with regression report; trend tracked in `data/bench/league_per_row_kb.json`.
- [x] **Predictor inflight cap per league.** `cfg.predictor_inflight_max_per_league` (default 64) prevents one league from saturating the predictor swarm; overflow returns `503 Service Unavailable + X-Reason: per_league_inflight_full` (Phase 11 §11.30 backpressure). Landed: predictor stores inflight count per league in Redis; pre-processing gate checks count vs cap; overflow returns HTTP 503 with reason header; proof test `test_predictor_inflight_cap_per_league.py` saturates one league, verifies 503 on next request; test `test_other_leagues_unaffected_by_cap.py` confirms other leagues proceed normally.
