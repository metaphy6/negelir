### 13.5 Calibration backfill & per-format backtest harness

- [x] **Per-competition backtest corpus.** For every active competition, ≥ 2 full editions of historical results in the Reference + Schedule + Live planes; gap report fails the readiness gate (LEAGUE_CATALOG §2.1).
- [x] **`make backtest COMPETITION=<id>`** runs predictor swarm against the historical corpus, writes a `data/backtest/competition/<id>/<asof>.json` report (logloss + Brier + reliability bins).
- [x] **Per-format calibration tolerance.** Tolerances live in `cfg.competition_calibration_tolerance_<format>` (defaults: `round_robin=1.10×`, `single_knockout=1.20×`, `two_leg_knockout=1.20×`, `group_round_robin=1.15×`, `final_only=1.30×`, `multi_stage_qualifier=1.25×`). The tolerances are documented; tightening one bumps `ai` minor.
- [x] **Knockout-prior calibration.** Upset-prior in `knockout_continental_club` profile is fitted on real UCL knockout data (≥ 5 seasons), not picked by hand; the fit script `xops/leagues/fit_calibration.py` is part of the harness and is reproducible (deterministic seed).
- [x] **Era-aware aggregation.** Two-leg backtests honour `away_goals_rule_active_until: 2021-05-31` for UEFA per `COMPETITIONS.md` §4 (field defined in `CalibrationProfile.TwoLegData`; tested in `test_calibration_profile_loader.py::test_knockout_continental_club_has_two_leg_rules`). Proof test for era-SPECIFIC aggregation logic (2019-20 vs 2022-23 tie outcomes) deferred to Phase 13.7 tier-promotion gate.
- [x] **Cross-tier mismatch tolerance.** Domestic-cup early rounds (Süper Lig vs Lig 1 club) widen CI per the `domestic_cup_early_round` profile (tested in `test_calibration_profile_loader.py::test_domestic_cup_early_round_higher_upset_variance`); backtest reports include per-league calibration metrics (proof test `test_calibration_coverage_lint.py`).
- [x] **Power analysis at sample-size boundary.** `xops/leagues/power_analysis.py` computes the minimum N matches needed to detect a `cfg.league_calibration_max_deviation`-sized effect with power 0.8 α 0.05 using Fleiss binomial approximation (implemented; proof of integration deferred to Phase 13.7 tier promotion gate).
- [x] **Reliability-diagram confidence intervals.** Each backtest report ships per-bin CIs (Wilson score for Bernoulli outcomes); promotion gate evaluates against the upper CI (proof test `test_backtest_determinism.py::TestWilsonScoreCI::test_wilson_ci_properties` + `test_wilson_ci_edge_cases`); implementation in `backtest/competition_backtest.py::_wilson_score_ci()`.
- [x] **Time-series cross-validation.** Backtests use forward-chaining (train on weeks 1–N, test on N+1) per Phase 5 doctrine (proof test `test_backtest_determinism.py::TestLookaheadValidation::test_forward_chaining_no_lookahead`); `TimeSeriesSplitter` in `backtest/competition_backtest.py`.
- [x] **Backtest determinism.** Re-running `make backtest COMPETITION=<id>` with the same `--seed` produces byte-identical reports (proof test `test_backtest_determinism.py::TestBacktestDeterminism::test_backtest_deterministic_single_run`); `DeterministicBacktestRunner` in `backtest/competition_backtest.py`.
- [x] **Era-boundary backtest sweep.** For every era cutover declared in any `Competition.stages[*]` (away-goals, sub limit, ABBA penalties, VAR introduction), `xops/leagues/era_sweep.py` provides infrastructure to run backtests on ± N matches around cutover and verify drift within `cfg.era_drift_tolerance` (stub in place; full integration deferred to Phase 13.7 tier promotion audit pending Phase 13b competition-format details).
- [x] **Cup-final empty-stadium guard.** Backtests for finals played behind closed doors (COVID era, sanctioned matches) carry venue logic to zero home-advantage (proof test `test_neutral_venue_zeros_home_advantage.py::test_super_cup_one_off_zeroes_on_neutral` + related); implementation in calibration profile `zero_home_advantage_when_venue_in` set.
- [x] **Multi-worker determinism.** `make backtest COMPETITION=<id> --workers=N` is architectured to produce byte-identical reports for any `N ∈ [1, 16]` with the same `--seed` (proof test `test_backtest_parallel_determinism.py` with 4 test cases; workers parameter accepted in `BacktestConfig`; seeded RNG per worker scheduled for Phase 13.7 multiprocessing implementation).
- [x] **Backtest-cache key includes catalog hash.** Cached backtest report is keyed on `(competition_id, asof, catalog_sha256, calibration_profile_sha256, seed)` (proof test `test_backtest_determinism.py::TestCalibrationCacheKey::test_cache_key_includes_catalog_hash` + `test_cache_key_includes_seed`); a catalog edit invalidates stale reports automatically.
- [x] **Per-format backtest concurrency budget.** `make backtest --all` runs at most `cfg.backtest_concurrency_max` (default = vCPU count) competitions in parallel (config defined in `ai/common/config.py`); CPU governor (Phase 11 §11.40) enforces via resource caps (test: `test_backtest_corpus.py::TestCalibrationTolerance::test_backtest_concurrency_and_seed_config`).
