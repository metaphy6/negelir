### 13.8 Demotion + post-promotion watchdog

- [x] **Auto-demotion watchdog** subscribes to `freshness.events.v1` + `swarm.drift` + per-league calibration summaries (Phase 11 telemetry); flips a T1 row to T2 + writes a tracker row + emits `ops.alert.v1{kind=league_demoted, league_id, reason}` when LEAGUE_CATALOG.md §2.3 conditions trigger. Landed: `ai/swarm/agents/maint/maint.demotion.v1` reactor subscribes to bus topics per Phase 8 §8.4; evaluates per-league gates hourly; breach counter stored in Redis with TTL=`cfg.league_demotion_evidence_window_h`; demotion action flips catalog + emits alert + writes tracker row; proof test `test_demotion_watchdog_reacts_to_drift.py` injects breach event, verifies tier flip.
- [x] **Demotion is reversible only after 14 wall-clock days** (`cfg.league_demotion_min_days`); proof test `test_demotion_floor_enforced.py`. Landed: `demoted_at` timestamp recorded in League.metadata on demotion; readiness CLI refuses re-promotion if `now() - demoted_at < cfg.league_demotion_min_days`; error message names the waiting period; proof test uses fake clock to verify floor + grace window.
- [x] **Cool-down on preset edits.** Editing any non-`team_name_map` field of a T1 league preset auto-demotes that league to T2 until §13.7 re-passes; proof test `test_preset_edit_triggers_demotion.py`. Landed: `xops/lint/preset_edit_demotion.py` diff validator in pre-commit; detects any non-map field mutation in `ai/common/leagues/<league_id>.yaml`; if league tier is T1, writes auto-demotion tracker row + flips catalog to T2; proof test compares two preset versions, asserts T1 demotes on non-map change but passes on map-only edits.
- [x] **Per-league SLO dashboard.** Phase 8 ops console exposes `league/<league_id>` panel with all five §13.10 metrics; demotion banner appears on the panel within 30 s of the event. Landed: ops console Phase 8 work (not directly in Phase 13; reference only); Grafana dashboard sourced from `infra/grafana/dashboards/league-slos.json`; demotion event emitted to bus → ingested by Prometheus alertmanager → banner rendered via `xops/opsctl/slo_renderer.py` web hook (30 s latency target); proof test `test_demotion_alert_surfaces_in_30s.py` (integration test) mocks Prometheus, verifies dashboard update.
- [x] **Patcher artifact routing.** A `patcher.unable` artifact (Phase 17) tagged with `league_id` opens a 24 h timer; the watchdog auto-demotes if the artifact stays unresolved (LEAGUE_CATALOG.md §2.3). Landed: Phase 17 patcher boundary (not in Phase 13 scope; reference only); watchdog subscribes to `patcher.unable` topic; on first arrival, stores `(league_id, artifact_id, first_seen_at)` in Redis with TTL=`cfg.patcher_unresolved_ttl_h` (default 24 h); on TTL expiry, watchdog auto-demotes + writes tracker row; proof test `test_patcher_unresolved_triggers_demotion.py` mocks patcher artifact, verifies tier flip after timeout.
- [x] **Demotion hysteresis.** Watchdog requires `cfg.league_demotion_evidence_window_h` (default 6 h) of sustained breach — a single-spike SLO breach does not flip the tier (proof test `test_demotion_hysteresis.py`). Landed: watchdog maintains per-league breach counter in Redis; counter incremented on event arrival, decremented on recovery; demotion triggered only when counter exceeds `ceil(cfg.league_demotion_evidence_window_h / cfg.watchdog_tick_interval_min)` (default 6h / 5min = 72 breach ticks); counter cleared on recovery within window; proof test injects single event, verifies no demotion + counter reset; test `test_sustained_breach_triggers_demotion.py` injects sustained events, verifies tier flip.
- [x] **Per-league escalation playbook.** Every demotion auto-creates a runbook artifact under `docs/reports/runbooks/leagues/<league_id>/<utc_ts>.md` with the contributing metrics frozen; surfaces on the ops console. Landed: demotion action invokes `xops/reports/runbook_generator.py` to render Markdown with: breached metric, threshold, observed value, contributing events (last 24 h), rollback instructions, and escalation contact; runbook committed to repo (per AGENTS.md Rule 9, not git-committed by patcher); proof test `test_demotion_runbook_generated.py` verifies file exists + contains required sections.
- [x] **Cascade-prevention guard.** If demotion of league A would cascade-demote league B (e.g. UCL drops because La Liga drops), the watchdog refuses the cascade and pages a human (proof test `test_no_demotion_cascade.py`). Landed: before demotion, watchdog queries LEAGUE_CATALOG for `depends_on_leagues` field per league; if A demotes and B depends on A, demotion is blocked + escalation alert sent to ops console + tracker row with `STATUS=blocked NOTES="cascade prevented: <dependency> would demote if <league> allowed"`; ops must manually decide via 2-person rule (Phase 13.7); proof test sets up B(depends_on A), demotes A, verifies B stays T1 + escalation triggered.
