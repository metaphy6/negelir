### 13.13 Era-aware rules & friendly-exclusion enforcement

- [x] **Away-goals era cutoff.** `Competition.stages[*].away_goals_rule_active` honoured at predict time; era cutover lives in the YAML, never in code. Landed: `away_goals_rule_active: bool` field in CompetitionStage dataclass; predictor reads field at tie-resolution time; pre-era backtests load stage with `away_goals_rule_active=false`; proof test `test_away_goals_era_cutoff.py` compares predictions pre/post cutoff, verifies tie outcome changes when flag flips.
- [x] **`international_friendly` publish-gate.** `swarm/predictor/_publish_gate.py` refuses to publish friendlies; API returns `409 Conflict` with `X-Reason: competition_excluded`. Proof test `test_friendlies_never_published.py`. Landed: publish_gate checks `competition.format == 'international_friendly'`; if true, skips emission + returns `PublishGateDenied{reason="format_excluded", format}`; API endpoint catches exception, returns 409; proof test sends friendly prediction, verifies no emit + 409 response.
- [x] **Format → market filter.** `single_knockout` refuses "double chance — draw" market emission; `final_only` refuses "to qualify for next round" market; lint refuses an extractor mapping these markets for those formats. Landed: `AllowedMarketsPerFormat` map in `ai/common/betting_markets.json` specifies per-format market allow-list; predictor gate checks `format in allowed_markets`; emitter refuses to publish disallowed market; lint rule `xops/lint/market_format_filter.py` scans extractors for disallowed mappings; proof test `test_market_format_filter_enforced.py` asserts 409 on disallowed market attempt.
- [x] **Path-dependent priors** for `multi_stage_qualifier` are bounded — a team that has not yet played in the qualifier returns `cold_start` for the "to qualify for tournament" market (no fabrication, doctrine #3). Landed: predictor checks team's appearance count in the qualifier stage; if 0, returns `cold_start` (not-yet-computed probability); does not fabricate a default; emitter handles `cold_start` by skipping market emission; proof test `test_multi_stage_qualifier_no_fabrication.py` asserts no market for team with 0 stage appearances.
- [x] **Extra-time + penalty-shootout modeling.** `single_knockout` and `two_leg_knockout` outputs include `outcome_in_90 | outcome_in_120 | outcome_pens` with conditional probabilities summing to 1 ± 1e-6 (proof test `test_knockout_conditional_probs_sum.py`). Landed: `KnockoutOutcome` dataclass carries three probabilities (win_90, win_120, win_pens); predictor normalizes outputs to sum exactly 1.0; proof test generates 1000 random knockout outputs, asserts all sums within tolerance; test `test_knockout_probs_exclusive.py` confirms mutual exclusivity (no match both win_90 AND win_pens).
- [x] **VAR-era cutoff.** Per-competition `var_active_from` field; pre-VAR backtests use a different prior for late-game red-card / penalty rates (proof test `test_var_era_prior_shift.py`). Landed: `var_active_from: date` field in Competition; predictor queries field at predict time; if fixture date < var_active_from, applies pre-VAR prior (higher red-card variance); backtests load competition with appropriate var_active_from; proof test compares predictions pre/post VAR cutoff, verifies red-card prior shifts.
- [x] **Golden-goal / silver-goal era awareness.** Pre-2004 UEFA knockouts honour golden/silver-goal extra-time semantics (sudden-death termination); proof test `test_golden_goal_era_terminates_on_first_goal.py`. Landed: `golden_goal_until: date` and `silver_goal_until: date` fields in CompetitionStage; predictor checks fixture date vs fields; if in era, applies sudden-death extra-time logic (first goal wins); proof test generates 2003 UEFA knockout fixture, verifies extra-time terminates on first goal.
- [x] **COVID 5-sub era.** `Competition.rules_variant.max_subs_window` honours the 2020-onward IFAB amendment (5 subs in 3 windows); pre-2020 backtests stay at 3-sub semantics (proof test `test_covid_sub_era_window.py`). Landed: `rules_variant.max_subs_in_window` field (default 3 pre-2020, 5 post-2020 during COVID window); predictor reads field when computing fatigue / substitution effects; proof test loads pre/post-COVID competition, verifies different fatigue outputs.
- [x] **Concussion-substitute additivity.** Concussion subs are additive to the standard limit and do not consume a substitution window; predictor's "time-to-fatigue" feature accounts for the additional fresh leg (proof test `test_concussion_sub_additive.py`). Landed: `rules_variant.concussion_subs_allowed: bool`; if true, predictor applies additional fresh-leg effect independent of standard sub limit; fatigue decay slows accordingly; proof test compares predictions with/without concussion-sub flag, verifies late-game goal probability changes.
- [x] **Drinks-break stamina recovery.** Hot-weather competitions (Qatar 2022, summer Süper Lig) declare `drinks_breaks: bool` per fixture; predictor's late-game stamina decay slows when set (proof test `test_drinks_break_late_stamina.py`). Landed: `Fixture.drinks_breaks: bool` field; predictor reads field in stamina-decay calculation; if true, applies recovery bonus in late-game phases; proof test creates hot-weather fixture, verifies stamina decay reduced in minutes 70-90.
- [x] **Olympic-football eligibility overlay.** Olympic men's tournament is U-23 with three overage outfield + one overage GK; eligibility resolver applies the overlay only to Olympic competitions (proof test `test_olympic_eligibility_overlay.py`). Landed: `Fixture.olympic_tournament: bool` field; when true, eligibility resolver applies age cap (U-23 base + 3 outfield + 1 GK exceptions); squad member lookup respects overlay during fixture eval; proof test creates Olympic fixture, verifies age cap applied correctly.
- [x] **Lint forbids hardcoded era constants.** `xops/lint/no_hardcoded_eras.py` refuses any `if year < 2021` / `if season >= '2020-21'` / similar literals in `swarm/predictor/` and `swarm/proofreader/` — eras live in YAML, never in code (proof test `test_no_hardcoded_era_constants.py`). Landed: lint rule scans swarm/predictor/*.py and swarm/proofreader/*.py for string/int year patterns; CI fails if found; proof test deliberately inserts hardcoded year check, verifies lint rejection.

#### 13.13.5 Rules-variant overlay

- [x] **`Competition.rules_variant` payload.** Captures sub limit (3 / 5 / 5+1 in extra time), max subs allowed in extra time, ABBA penalty order vs ABAB, IFAB-trial flags (e.g. permanent concussion subs), match length variations (futsal-style halves are out of scope but the schema reserves the field). Predictor reads from the overlay; §13.0 #30 retired. Landed: `RulesVariant` dataclass in `ai/common/schemas/competitions.py` with all fields; Competition carries `rules_variant: RulesVariant` field; lint enforces non-null; proof test `test_rules_variant_schema_coverage.py` verifies all documented fields present.
- [x] **Lint forbids hard-coded rules constants** in `swarm/predictor/` and `swarm/proofreader/`; `xops/lint/no_hardcoded_rules.py` scans for `MAX_SUBS = ` / `PENALTY_ORDER = ` / similar literals. Landed: lint rule scans swarm code for uppercase constant assignments matching rules-related patterns; CI fails if found; proof test deliberately inserts `MAX_SUBS = 3` constant, verifies lint rejection.
- [x] **Rules-variant resolution test.** `test_rules_variant_resolution.py` asserts predictor output for the same fixture differs when the rules variant changes (e.g. 3-sub vs 5-sub effect on late-game goal probability). Landed: test creates identical fixture with two rules_variant configs (3-sub vs 5-sub); runs predictor on both; asserts prediction outputs differ (goal probability shifts); test confirms late-game scenarios show effect.
