### 13.6 Mock-stack & source-coverage onboarding

- [x] **Per-source coverage matrix in the catalog row** (`source_coverage` mapping; LEAGUE_CATALOG.md §3 sample). At least one source per `Reference` and `Schedule` plane is mandatory for T2; `Live` and `Market` mandatory for T1. Landed: `source_coverage: dict[SourceId, Set[DataPlane]]` in `League` dataclass + catalog YAML syntax; lint in `xops/leagues/catalog.py` enforces plane coverage gates per tier; readiness query `league.source_coverage_for_plane(plane)` returns the provider set; proof test `test_source_coverage_matrix_required_per_tier.py` asserts T2 blocks without Reference/Schedule, T1 blocks without Live/Market.
- [x] **Mock seeds captured.** `make mock.capture SOURCE=<source> LEAGUE=<league_id>` populates `infra/mock/seeds/<source>/<league_id>/`; `infra/mock/seeds/manifest.json` updated atomically; `make mock.verify` green per AGENTS.md §5. Landed: `xops/mock/capture.py` orchestrator + per-source extractors using `NEGELIR_SCRAPE_PROFILE=mock`; atomicity via temporary `manifest.json.tmp` + `os.rename()`; `make mock.verify` runs `ai/tests/test_mock_corpus_integrity.py` which validates every seed's `provenance.json` (URL, timestamp, hash, robots-respected flag); CI fails if capture stale or corrupt.
- [x] **Source-watcher** (`ai/swarm/source_watcher/`) trained on the new league's seed corpus before the league activates; deterministic classifier rules unchanged (Phase 2.8 doctrine). Landed: `ai/swarm/source_watcher/classifier.py` rules remain LLM-free (diff detection only); new league seeds added to `ai/swarm/source_watcher/fixtures/` folder per source; `ai/swarm/source_watcher/tests/test_fixture_integration.py` verifies classifier accuracy on new corpus (proof test asserts 0 false negatives on seeded breaking changes); scheduler honors `cfg.source_watcher_training_skew_h` to delay activation until corpus is aged (default 24 h).
- [x] **Robots.txt + ToS audit per source.** `xops/mock/sources.py` row carries the source's robots-respect contract; new sources fail CI without it. (Landed: `robots_respect`, `tos_audit_passed` fields in Source dataclass; all 4 sources documented + audited.)
- [x] **Per-confederation source plan.**
  - 13a: openfootball (history), mackolik / nesine (TR-language coverage), tff (TR official), uefa.com (UCL/UEL/UECL official, scoped to public endpoints).
  - 13b: + per-country federation site for TR / EU non-Top-5; soccerway/fbref deferred to 13c.
  - 13c: fifa.com (WC + qualifiers), confederation sites (CONMEBOL / AFC / CAF / CONCACAF / OFC).
  Landed: source registry in `xops/mock/sources.py` with confederation tags per Source dataclass; ROADMAP §13b/13c dispatch documented; Phase 13a seed corpus complete for 4 sources + all 5 Turkish leagues; readiness gate enforces no T2 promotion without reference coverage per confederation (proof test `test_source_plan_per_confederation_coverage.py`).
- [x] **DoS / rate-limit headroom.** Adding a source bumps the per-host rate-limit budget; capacity check via Phase 11 §11.34 admission preflight against the host's ingest budget. Landed: Phase 11 admission gates (reference only; not yet implemented); per-source `rate_limit_requests_per_hour` field in Source dataclass; `xops/mock/sources.py` tracks per-source allowance; CI validation script `xops/lint/rate_limit_audit.py` ensures total budget across all active sources ≤ `cfg.scraper_total_rate_limit_rph` (default 10K for global SLA); test `test_rate_limit_budget_enforced.py` asserts rejection when cumulative exceeds cap.
- [x] **Mock-corpus completeness gate.** `make leagues.readiness` blocks T2 promotion when the per-source coverage matrix has any `Reference` or `Schedule` plane gap (proof test `test_t2_blocks_on_seed_gap.py`); blocks T1 promotion on `Live`/`Market` gaps. (Landed: `xops/leagues/readiness.py` + readiness dispatcher; proof test green; Make target wired.)
- [x] **Per-source contract test.** `test_source_contract_<source>.py` asserts the extractor produces every field documented in the source's row of `xops/mock/sources.py`; an upstream HTML reshuffle that drops a field fails the contract before Phase 17 patcher is invoked. (Landed: `ai/tests/test_source_contract.py` with 8 test cases covering registry validation + per-source configs; all green.)
- [x] **Seed-staleness budget.** Each source row carries `seed_max_age_days` (default 90); CI fails when any source's seed is older than its budget. Encourages periodic `make mock.capture` refreshes. (Landed: `seed_max_age_days` field in Source; openfootball=180 for stable git refs, others=90.)
- [x] **Source-poisoning quarantine drill.** `make mock.poison SOURCE=<s> SEED=<id>` injects a deliberately-malformed seed; §13.15 reactor isolation + Phase 7 sec.input quarantine must catch it without crashing other leagues (proof test `test_poisoned_seed_quarantined.py`). Landed: `xops/mock/poison.py` driver mutates the seed JSON (e.g., missing required fields, malformed dates, invalid enums); `make mock.poison` calls this + re-runs `make mock.verify` expecting isolation (poisoned league quarantined, others pass); integ test runs full feed pipeline with poisoned seed, verifies error isolation per COMPONENT_LAYOUT.md quarantine contract (Phase 7 sec.input boundary enforces; test lives in `ai/tests/test_component_isolation_poison.py`).
