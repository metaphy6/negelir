### 13.14 International squad / national-team plane integration (13a foundation; expanded 13c)

- [x] **National-team identity registry** (`country_id ↔ national_team_id`) — single source for international competitions; covered by `Player.eligibility`. Landed: `national_team_id` field in Player.eligibility with `country_id` foreign key to Country table; loader enforces referential integrity; lint forbids duplicate `(player_id, national_team_id)` pairs; proof test `test_national_team_identity_unique.py` verifies no duplicates.
- [x] **Squad rotation features.** Tournament-bubble effects (squad fatigue, rotation) modelled as a feature input to `international_*` profiles; per `COMPETITIONS.md` §1.2 international_championship. Landed: `squad_rotation_ratio` feature extracted from player appearance history during tournament window; input to international_* calibration profiles; profiles define per-position rotation elasticity; proof test `test_squad_rotation_feature.py` compares predictions with/without rotation modelling, verifies goal probability shifts.
- [x] **Player-club separation.** Injury / suspension data (Phase 21 enrichment) joins on `Player.eligibility` — proof test `test_player_injury_at_club_propagates_to_national_squad.py`. Landed: Phase 21 enrichment infrastructure (reference only; not directly Phase 13); injury events tagged with both `club_id` and `country_id` when applicable; eligibility query can filter on national-team context; proof test creates injury, verifies it's queryable via both club and national-team lookups.
- [x] **Friendly inclusion guard.** Pre-tournament friendlies feed sentiment + news only; never feed predictor training (proof test `test_friendly_excluded_from_training.py`). Landed: backtest corpus loader checks `competition.format == 'international_friendly'`; if true, excludes fixture from training set (news only); proof test loads corpus with friendlies, verifies training set excludes them, news set includes them.
- [x] **FIFA international-window calendar.** Loader reads `xops/leagues/fifa_windows.yaml` (per FIFA-published schedule); club-fixture availability features mark players unavailable during their national side's window (proof test `test_fifa_window_unavailability.py`). Landed: `xops/leagues/fifa_windows.yaml` documents FIFA windows per year; loader ingests and caches; predictor queries windows when computing player availability; club-match during window marks national-team players as unavailable; proof test creates club fixture during FIFA window, verifies national-team players marked unavailable.
- [x] **Naturalisation / dual-citizenship reconciliation.** `Player.eligibility` accepts multiple `national_team_id` entries with `effective_from` / `effective_to`; switching nationalities (e.g. Diego Costa) preserves history without rewriting old fixtures (proof test `test_dual_citizenship_history_preserved.py`). Landed: `Player.eligibility` is a list; each entry carries `national_team_id`, `effective_from: date`, `effective_to: date | null`; loader enforces no overlapping active ranges per player; predictor queries eligibility at fixture date to determine valid teams; proof test creates naturalised player, verifies old fixtures query old nationality, new fixtures query new nationality.
- [x] **U-team and women's competition isolation.** U-21 / U-19 / women's national-team competitions are separate `Competition` rows; their predictions never bleed into senior men's calibration (proof test `test_age_gender_competition_isolation.py`). Landed: `Competition.competition_type: enum` includes `senior_men`, `senior_women`, `u21_men`, `u19_men`, etc.; backtest loader segregates by type; proofs separately; calibration isolation enforced by separate profile per type; proof test verifies no fixture from U-21 competition appears in senior calibration set.
