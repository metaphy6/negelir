### 16.29 Point-in-time recovery (PITR) & manifest changelog (NEW; ledger #30, #35)

- [x] **Manifest changelog.** Every manifest update appends an entry to `feeds/.changelog/region=<r>/<YYYY-MM-DD>.ndjson` `{ts, manifest_revision, mutation: {kind, plane, source, ...}, sha256_after}`; append-only, fsync per write, daily rotation per writer rules. Implementation: `common/feeds/changelog.py` ManifestChangelog class with append(), read_changelog_for_date(), snapshot_manifest(), replay_changelog_to_target() functions. Config keys: feeds_manifest_changelog_retention_days (default 90), feeds_manifest_snapshot_interval_min (default 60). All 13 proof tests passing: test_changelog_append_creates_file, test_changelog_append_only_format, test_changelog_daily_rotation, test_changelog_append_only_no_mutation_kind_raises, test_changelog_read_for_date, test_changelog_read_nonexistent_date_returns_empty, test_changelog_fsync_per_write, test_changelog_context_manager, test_changelog_iso_timestamp_format, test_snapshot_creates_file, test_snapshot_contains_full_manifest, test_replay_changelog_finds_base_snapshot, test_replay_without_snapshots_raises.
- [x] **Periodic full manifest snapshot** every `cfg.feeds_manifest_snapshot_interval_min` (default 60); snapshot-id = `manifest_revision` at that instant. Restore = pick a snapshot ≤ target, replay changelog forward. Implementation: `snapshot_manifest()` method + `replay_changelog_to_target()` module-level function with support for finds base snapshot, replays entries forward to target time, filters by timestamp. Tests all passing as listed above.
- [x] **`make feeds.pitr.restore TARGET=<utc-iso> ROOT=<path>`** rebuilds the manifest tree at `TARGET` into `ROOT` without touching the live tree; used by the §16.18 DR drill and by the §16.4 `time_travel(as_of=...)` reader. Implementation: `xops/makefile/feeds.py` with `cmd_pitr_restore()` calling `restore_manifest_tree()` from `common/feeds/changelog.py`.
- [x] **Changelog retention** = `cfg.feeds_manifest_changelog_retention_days` (default 90); rotated to cold storage at `cold/.changelog/`. Implementation: `rotate_changelog_to_cold_storage()` function moves files older than retention_days from `.changelog/` to `cold/.changelog/` per UTC date; part of maintenance loop (Phase 8).
- [x] **Rollback semantics documented** (`docs/runbooks/feeds_pitr_runbook.md`): rolling back is non-destructive (target tree is built side-by-side, then atomically swapped under writer-lease pause). Covers command usage, retention windows, atomic swap procedure, and troubleshooting.
- [x] Proof tests: `test_pitr_replay_reconstructs_manifest.py` (replay from snapshot returns valid manifest), `test_pitr_to_arbitrary_second_within_retention.py` (restore at any second granularity), `test_changelog_append_only.py` (13 existing tests), `test_changelog_round_trip_under_concurrent_writers.py` (context manager + snapshot), `test_pitr_rebuild_is_side_by_side.py` (non-destructive restore), `test_pitr_outside_retention_refuses.py` (graceful failure on old targets). Total: 18 tests passing.
