### 16.0 Wrong-assumption ledger (retire before any code lands)

> Mirrors the Phase 13 §13.0 pattern. Every retired assumption maps
> to a proof test. `xops/lint/phase16_ledger.py` refuses a PR that
> introduces a sub-section without ticking the corresponding ledger
> entry, and refuses a PR that flips an entry to retired without a
> green proof test in the same diff.

| # | Wrong assumption (held earlier in the design) | Correction | Proof test |
|---|---|---|---|
| 1 | "Byte-identical predictor outputs prove parity between the DB-reading and Feed-reading paths." | DB and Feed produce **field-equal** records, never byte-equal — the canonical-JSON re-projection drops Postgres-side defaults. Parity gate is **field-equal** (`Record(...) == Record(...)`) and **prediction-equal within 1e-9** on the consensus head, not byte-equal. | `test_parity_field_equal_not_byte_equal.py` |
| 2 | "`FeedCursor = (file_path, byte_offset, manifest_etag)` is a stable resume token." | File path mutates at midnight rotation (`.ndjson` → `.ndjson.zst`); a cursor pinned to the uncompressed name breaks at 00:00 UTC. Cursor is `(plane, source, calendar_date_utc, logical_offset_records, manifest_revision)`. Reader maps `(date, offset)` → physical bytes per the current manifest. | `test_cursor_survives_midnight_rotation.py` |
| 3 | "Schema registry can change while consumers are reading." | A consumer that started a `stream()` against `score@v1` must see `score@v1` semantics until it closes the stream, even if `v1` flips to `deprecated` mid-run. Registry is **frozen-at-stream-open** (each open snaps the registry SHA and pins it through the lifetime of the iterator). | `test_registry_pinned_per_stream.py` |
| 4 | "`json.dumps(sort_keys=True)` produces canonical bytes." | It does not normalize Unicode (NFC), does not enforce no-trailing-whitespace on numbers (`1.0` vs `1`), and does not constrain timestamp surface form. Canonicalization is a named function `common.feeds.canonical.encode(record) -> bytes` with its own conformance corpus. | `test_canonical_encoder_conformance.py` |
| 5 | "Snapshot at hour H is closed at H+0." | Records arrive late (network delay, retraction). Hourly snapshot is **closed at H + `cfg.emitter_snapshot_grace_minutes`** (default 10 min) with a watermark contract (§16.4); records arriving after the watermark go into the next hour's snapshot AND raise a `feeds_late_record_total` counter. | `test_snapshot_watermark_grace.py` |
| 6 | "Reader can poll the manifest every N ms to detect new records cheaply." | LIST-on-S3 costs money; on local disk a busy poll burns CPU. Live consumers subscribe to the `feeds.pointer.v1` Redis stream (§16.6) for wake-up; polling is the fallback only. | `test_reader_uses_pointer_stream_when_available.py` |
| 7 | "Retractions can be expressed by rewriting NDJSON." | Append-only forbids it (EMITTER §6 #4). Retractions ship as **tombstone Records** in the same plane (`tombstone: true`, `retracted_at`, `reason`); snapshot builder applies tombstones at watermark-close. | `test_tombstone_round_trip.py`, `test_snapshot_excludes_tombstoned_stable_ids.py` |
| 8 | "Per-`(plane, source)` writer is enough fairness." | A noisy source (e.g., `nesine` market ticks) can saturate disk bandwidth and starve quieter sources. Writer pool enforces a **per-source token-bucket** with a fairness floor (`cfg.emitter_per_source_floor_pct`, default 5 %) so no source drops below 5 % of total disk-write budget. | `test_per_source_fairness_floor.py` |
| 9 | "EOL schema versions are blocked at PR-time only." | Without a runtime gate, a stale binary can resurrect EOL writes after the registry flips. Writer **refuses to open a writer for an `eol` version at process start** (hard fail, supervisor pages). | `test_writer_refuses_eol_version_at_startup.py` |
| 10 | "S3 driver `list_prefix` is good enough for cold-start." | LIST is paginated, eventually consistent on some providers, and bills per request. Cold-start uses the manifest only; LIST is a degraded fallback gated by `cfg.feeds_s3_list_fallback_enabled` (default `off` in prod). | `test_cold_start_uses_manifest_not_list.py` |
| 11 | "Predictions never need to be invalidated retroactively." | Cascade events (postponed/abandoned/awarded matches per Phase 13.51) emit `predict.invalidated.v1`; the feed plane (`feeds/predict_invalidated.v1`) carries the persisted log, the bus carries only the wake-up. | `test_predict_invalidated_dual_write.py` |
| 12 | "All records are equally public." | Phase 11 introduced `data_class` labels; Phase 16 must propagate them per record and the read ACL must filter by class, not just `(plane, source)`. | `test_pii_record_filtered_by_acl.py` |
| 13 | "Snapshots can be rebuilt deterministically from NDJSON alone." | They cannot — the registry version active at snapshot-build time and the tombstones applied at that time are part of the input. Snapshot footer records `(registry_sha256, tombstones_applied_count, watermark_at)`; rebuild is deterministic only when those three are pinned. | `test_snapshot_rebuild_requires_registry_pin.py` |
| 14 | "Compression at midnight is atomic enough." | A crash during compression leaves both `.ndjson` and `.ndjson.zst` for the same date. Rotation protocol is `compress → fsync → checksum → atomic rename → unlink original → fsync(parent)`; recovery on startup detects half-states and resumes/rolls back. | `test_midnight_rotation_crash_recovery.py` |
| 15 | "A graceful SIGTERM has unbounded time to flush." | Kubernetes kills after 30 s by default. Emitter must drain within `cfg.emitter_shutdown_grace_s` (default 25 s) and signal **not-ready** at SIGTERM-receipt + 0 ms so the load-balancer stops sending wake-ups. | `test_graceful_shutdown_within_grace.py` |
| 16 | "Cost is a Phase 14 problem." | Every S3 PUT/LIST/GET and KMS Decrypt costs money; a buggy retry loop can produce a runaway bill in minutes. Per-driver per-op budget surfaced as `feeds_store_cost_usd_total{driver,op}` with a hard ceiling per `cfg.feeds_store_daily_usd_cap` (default $5 in dev, env-tunable). | `test_s3_cost_budget_caps.py` |
| 17 | "All planes share one retention policy." | Editorial may need 2 years for compliance, market only 30 days for cost. Retention is per-plane (`cfg.feeds_retention_<plane>_ndjson_days`, `cfg.feeds_retention_<plane>_snapshot_days`). | `test_per_plane_retention_honoured.py` |
| 18 | "Multi-region replication is Phase 14's only concern." | Region prefix (§16.18) is part of the Phase 16 layout from day one — Phase 14 only enables the cross-region copy job. Without the prefix, retro-fitting partitions later is destructive. | `test_region_prefix_present_from_day_one.py` |
| 19 | "Backfill and live emit can race because both write-paths are idempotent." | Idempotent ≠ safe. A live writer holding the lease for `(plane, source)` and a backfill tool writing into a sidecar root can produce inconsistent manifest counts if both update the manifest. Backfill writes only to `feeds_backfill/`; promotion is a **lease-acquiring atomic rename** that pauses live emit for that partition. | `test_backfill_pauses_live_emit_for_partition.py` |
| 20 | "Per-record signing is Phase 17's problem." | The envelope **field** must be reserved now (`signature: str|null`) so adding HMAC at Phase 17 isn't a schema bump. Phase 16 ships the field always-`null` plus a verify-passes-on-null lint. | `test_signature_field_reserved.py` |
| 21 | "All planes can be read independently at any `as_of`." | A predictor that joins `lineup ⋈ schedule` at `as_of=T` will produce inconsistent reads if each plane's snapshot watermark is independent. **Joined reads require a coherent cross-plane watermark** (`snapshot.ready.v1{as_of, planes_ready: [...]}`); the reader exposes `joined_snapshot(planes=[...], as_of=...)` that refuses if any plane is not yet ready at `as_of`. | `test_joined_snapshot_refuses_on_partial_readiness.py`, `test_snapshot_ready_event_per_plane.py` |
| 22 | "At-least-once + reader-side dedup is enough — producers don't need idempotency keys." | A retried HTTP scrape can produce two records with the same logical content but different `captured_at`, defeating dedup keyed on `(stable_id, captured_at)`. Producers MUST supply `idempotency_key = sha256(canonical_payload)` in the envelope; reader dedup keys on `(stable_id, idempotency_key)` so retries collapse regardless of `captured_at` jitter. | `test_idempotency_key_collapses_retries.py`, `test_writer_refuses_record_without_idempotency_key.py` |
| 23 | "A reader can hold an entire snapshot in memory." | Phase 13a peak `score` snapshot at hour H is ~80 MiB decoded; a trainer reading 30 days holds 60 GiB. Reader API MUST support **bounded streaming** with predicate + projection pushdown (only requested columns + only matching rows are decoded); a hard `cfg.feed_reader_per_call_max_resident_mb` (default 512) caps a single `snapshot(...)` invocation. | `test_snapshot_streams_under_memory_cap.py`, `test_projection_pushdown_skips_columns.py`, `test_predicate_pushdown_skips_rowgroups.py` |
| 24 | "JSONSchema validation can happen at flush time." | Flush-time validation drops whole batches under load and breaks the per-record CRC contract. Validation runs **at `enqueue()`-time**, before the canonical encoder, before the CRC; invalid records are quarantined immediately to `feeds/sec_quarantine.v1` with `reason=schema_violation` and never enter the live partition. | `test_schema_violation_quarantined_pre_flush.py`, `test_flush_never_drops_validated_batch.py` |
| 25 | "Cross-plane referential integrity is the proofreader's problem." | A `lineup` Record whose `match_stable_id` is not in the active `schedule` window will silently corrupt joined reads in the trainer. The writer MUST consult an in-memory rolling index of `schedule.stable_id` (TTL = `cfg.emitter_xref_window_h`, default 168 = 7 d) and quarantine orphan `lineup`/`market`/`score` records with `reason=ref_integrity_violation`. | `test_orphan_lineup_quarantined.py`, `test_xref_index_ttl_honoured.py`, `test_late_schedule_promotes_quarantined_lineup.py` (when the missing `schedule` arrives, the quarantined `lineup` is auto-promoted within `cfg.emitter_xref_promotion_max_s`, default 300). |
| 26 | "Right-to-erasure is a Phase 9 problem." | GDPR erasure on a `pii` record requires (a) tombstone in NDJSON, (b) snapshot rebuild excluding the tombstoned row, (c) backup re-encryption / key-shred for cold storage past retention horizon. The full surface MUST be designed in Phase 16 — Phase 9 only wires the request endpoint. | `test_erasure_request_creates_tombstone.py`, `test_erasure_rebuilds_affected_snapshots.py`, `test_erasure_key_shred_marks_cold_storage_unreadable.py`, `test_erasure_completes_within_sla.py` (`cfg.feeds_erasure_sla_h`, default 720 = 30 d). |
| 27 | "Snapshot freshness is implicit — trainers can `LIST` and pick the latest." | Trainers reading mid-build see partial snapshots (some part files committed, some not). Snapshot builder MUST publish `feeds.snapshot.ready.v1{plane, as_of, registry_sha, manifest_etag, sha256_of_parts}` **only after** the manifest update is fsynced; trainers subscribe and consume only `ready` events. | `test_snapshot_ready_published_after_manifest_fsync.py`, `test_trainer_blocked_until_ready_event.py` |
| 28 | "Reader-side caching is unnecessary." | Re-decoding the same `(plane, as_of, day)` parquet across 8 predictor replicas wastes 7× CPU. A **per-process LRU snapshot cache** (`cfg.feed_reader_snapshot_cache_max_mb`, default 1024) plus a **bloom filter sidecar** per part (`*.bloom`, keyed on `stable_id`) reduces stable-id lookups from O(n) to O(1) with bounded false-positive rate `cfg.feeds_bloom_fpr_max` (default 0.01). | `test_snapshot_lru_cache_reduces_redecodes.py`, `test_bloom_sidecar_present_per_part.py`, `test_bloom_lookup_zero_false_negatives.py`, `test_bloom_fpr_within_budget.py` |
| 29 | "Pointer stream is sufficient for cross-plane joined wake-ups." | A consumer joining `lineup ⋈ schedule` woken on a `lineup` pointer may read before the corresponding `schedule` row is visible. Cross-plane joined consumers subscribe to `feeds.snapshot.ready.v1` (per-`as_of`, per-plane) instead and only proceed when **all required planes** are ready at the same `as_of`. | `test_joined_consumer_waits_for_all_planes_ready.py` |
| 30 | "Filesystem snapshots are sufficient backups." | A FS snapshot misses in-flight writes between fsyncs and cannot reconstruct a single point in time across multiple writers. Feeds need **PITR via a manifest changelog** (`feeds/.changelog/<region>/<YYYY-MM-DD>.ndjson`, append-only) plus periodic full manifest snapshots; restore replays the changelog forward to the target wall-clock. | `test_pitr_replay_reconstructs_manifest.py`, `test_pitr_to_arbitrary_second_within_retention.py`, `test_changelog_append_only.py` |
| 31 | "OpenTelemetry tracing is a Phase 14 concern." | Without `traceparent` propagation in the envelope from day one, cross-component traces (Phase 9 gateway → reader → writer → bus → reactor) are broken at every Phase 16 hop. Envelope MUST carry `trace_context: {traceparent, tracestate}` (W3C Trace Context); writer/reader honour it without recomputing span IDs. | `test_traceparent_round_trip.py`, `test_writer_continues_upstream_span.py`, `test_reader_emits_span_per_call.py` |
| 32 | "Phase 8 schema fingerprints and feed schema versions are independent." | A Phase 8 fingerprint mismatch (extractor schema drifted) MUST invalidate the writer's `(plane, source, version)` lease — otherwise the writer keeps emitting `v1`-shaped rows with `v2`-shifted semantics. Writer subscribes to `schema.fingerprint.changed.v1` and pauses + pages on mismatch; resumes only after operator ACK or auto-promotion via the patcher (Phase 17). | `test_schema_fingerprint_pauses_writer.py`, `test_writer_resumes_after_operator_ack.py`, `test_writer_resumes_after_patcher_promotion.py` |
| 33 | "Static `(plane, source, date, region)` partitioning is enough." | At Phase 13a peak, a hot league (e.g. Premier League `market` plane) produces single-partition rates that exceed one writer's throughput. Layout MUST allow an opt-in `league_id_bucket=<00..NN>` sub-partition (`cfg.emitter_league_bucket_count`, default 1; per-plane override) without breaking cursors — cursor format gains an optional `league_bucket` field that defaults to `null`. | `test_league_bucketed_layout_round_trip.py`, `test_cursor_compatibility_across_bucket_change.py`, `test_repartition_does_not_break_active_readers.py` |
| 34 | "Read-after-write is immediate." | `cfg.emitter_fsync_mode=batch` introduces up to `cfg.emitter_fsync_batch_ms` of latency. The read-side contract MUST define **visibility semantics per fsync mode**: `always` ⇒ visible after `enqueue()` returns; `batch` ⇒ visible after the next batch boundary; `off` ⇒ visible after process exit (test-only). Reader exposes `visibility_horizon_ms` so a strict caller can poll. | `test_visibility_horizon_matches_fsync_mode.py`, `test_strict_caller_blocks_until_horizon.py` |
| 35 | "Replay is just re-reading the NDJSON." | Root-cause-analysis ("what did predictor X see at time T?") demands the manifest-as-of-T, registry-as-of-T, AND tombstone-set-as-of-T. Reader exposes `time_travel(as_of=T)` that rebinds all three; without it, replay sees post-fact retractions and gives wrong answers. | `test_time_travel_excludes_post_t_tombstones.py`, `test_time_travel_uses_contemporaneous_registry.py`, `test_time_travel_manifest_revision_is_deterministic.py` |
| 36 | "Compression is `zstd` and that's final." | `zstd` codec/level and per-plane dictionaries materially affect cost — `market` ticks compress 3–5× better with a per-plane trained dictionary. Codec/level/dict are configurable per plane (`cfg.emitter_compression_codec_<plane>`, `cfg.emitter_compression_level_<plane>`, `cfg.emitter_compression_dict_path_<plane>`); registry records the tuple per file in the manifest so readers select the right decompressor without sniffing. | `test_per_plane_codec_round_trip.py`, `test_dict_compression_meets_ratio_target.py`, `test_codec_change_does_not_break_old_files.py` |
| 37 | "A single `manifest.json` per region scales forever." | At Phase 13a roster a single mutable JSON file with hundreds of writers updating it becomes a hot lock (write-amplification + LIST cost). Manifest MUST be **sharded per `(plane, source)`** with a top-level `manifest_index.json` (rebuilt only on shard creation/deletion); reader walks the index then reads only relevant shards. | `test_manifest_sharded_per_plane_source.py`, `test_manifest_index_rebuild_only_on_topology_change.py`, `test_concurrent_writers_no_index_contention.py` |
| 38 | "Schema validation alone is enough; semantic invariants belong upstream." | Mandatory invariants per plane (`score.payload.score_h >= 0`, `lineup.starting_eleven.length == 11`, `market.odds.decimal >= 1.01`, `schedule.kickoff_at > captured_at - 7d`) MUST be enforced at the writer too — extractor bugs must not silently emit semantically-impossible rows that snapshot/parity gates only catch days later. Per-plane `invariants.py` declares pure functions; writer runs them at `enqueue()`-time alongside JSONSchema validation. | `test_per_plane_invariants_enforced.py`, `test_invariant_violation_quarantined_with_reason.py`, `test_invariants_have_full_unit_coverage.py` |
| 39 | "Snapshots can be full-rebuild every hour." | Full hourly snapshots at Phase 13a peak cost ~3 GiB/h on the `score` plane; trainers re-download all of it per epoch. Snapshot builder MUST support **delta mode** (`cfg.emitter_snapshot_mode = full|delta`, default `delta`): each hour writes only deltas vs the previous hour; periodic compaction (`cfg.emitter_snapshot_compaction_hours`, default 24) merges deltas into a sealed full snapshot. Reader transparently joins deltas. | `test_delta_snapshot_round_trip.py`, `test_delta_compaction_byte_equivalent_to_full.py`, `test_reader_joins_deltas_transparently.py`, `test_delta_disk_savings_meet_target.py` (≥ 60 % vs full on the reference workload). |
| 40 | "Bad records can only quarantine themselves." | A pathological upstream (e.g., a source that suddenly emits 10× malformed rows / sec) can drown the quarantine plane and starve healthy traffic. Each plane has a **circuit breaker** keyed on `(plane, source)` quarantine-rate over a rolling window (`cfg.emitter_circuit_quarantine_window_s`, default 60); when rate > `cfg.emitter_circuit_quarantine_threshold` (default 0.30 = 30 % of inbound), the breaker opens — writer rejects all inbound for that `(plane, source)` with `proof.flag{kind=circuit_open}`, pages, and re-tests every `cfg.emitter_circuit_half_open_s` (default 300). | `test_circuit_opens_on_quarantine_storm.py`, `test_circuit_half_open_recovers.py`, `test_circuit_isolated_per_source.py` |

`xops/lint/phase16_ledger.py` enforces: every retired-row PR ships a green proof test in the same diff; every new sub-section in this phase references at least one ledger entry by number.
